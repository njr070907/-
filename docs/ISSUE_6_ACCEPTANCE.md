## 现场启动方式

答辩指定电脑使用本地服务作为第一备用方案：

```powershell
# 终端一：仓库根目录
.\scripts\Reset-Demo.ps1 -ResetDemo
.\backend\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000

# 终端二：仓库根目录
Push-Location frontend
npm run dev
```

浏览器打开 `http://localhost:5173`。如果本地服务不能恢复，播放 [主流程短录屏](videos/issue-4-main-flow.mp4)，并记录故障现象；不要在答辩现场临时改代码。
