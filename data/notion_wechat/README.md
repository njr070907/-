## 目录

- notices/：适合在 GitHub 阅读的 Markdown 镜像。每个文件的“原文”部分保留 Notion 页面正文。
- raw/：一条记录一个 JSON，字段对齐 data/raw/example_notice.json，可在人工核对后复制到 data/raw/ 参与 MVP 导入。
- manifest.json：机器可读索引，保留 Notion 页面链接、原始来源链接、分类、状态、摘要、文件路径与正文哈希。
- INDEX.md：按日期列出的浏览索引。

## 导入边界

此归档默认不参与启动时的演示数据导入，避免把已过期或未核对的历史通知混入答辩演示。需要使用某一条记录时，先核对原文、日期和来源，再将对应 raw/*.json 复制到 data/raw/ 后运行现有导入命令。
